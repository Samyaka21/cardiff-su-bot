# 🎓 Cardiff SU AI Assistant

An intelligent, source-aware chatbot designed to help students at Cardiff University navigate SU events, housing advice, and society information.

### ✨ Key Features
* **Hourly Live Updates:** Automatically scrapes the Cardiff SU website every hour using GitHub Actions.
* **Source-Aware:** Provides direct links to tickets and official SU pages.
* **Smart Search:** Uses ChromaDB and Vector Embeddings to find the most relevant information.

### 🛠️ Tech Stack
* **Frontend:** Streamlit
* **AI Brain:** Google Gemini 2.0
* **Database:** ChromaDB
* **Automation:** GitHub Actions (Python Scraper)
